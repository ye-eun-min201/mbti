## 📌 서비스 소개

질문에 답하면 **16가지 MBTI 유형** 중 나에게 해당하는 유형을 결과로 보여줍니다.

<br/>

## ✨ 주요 기능

- 📝 MBTI 성향 질문 제공
- 👆 선택지 클릭으로 간편하게 응답
- 🎯 응답 결과를 분석하여 MBTI 유형 도출
- 📋 나의 MBTI 유형 결과 확인

<br/>

## 🚀 시작하기

```bash
# 레포지토리 클론
git clone https://github.com/ye-eun-min201/mbti.git

# 디렉토리 이동
cd mbti

# 패키지 설치
npm install

# 로컬 실행
npm start
```

> 브라우저에서 `http://localhost:3000` 으로 접속하세요.
